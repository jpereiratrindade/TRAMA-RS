Integração

API pronta para consumo

Respostas JSON usam envelopes data/meta. Camadas cartográficas usam GeoJSON EPSG:4326.

Rotas úteis

Abra no navegador ou use em qualquer cliente HTTP.

GET /v1/municipios?q=bageGET /v1/municipios?bioma_id=pampaGET /v1/coredes/campanha/municipiosGET /v1/mapa/municipios.geojson
curl -fsS 'http://localhost:8080/v1/municipios?q=bage'

# Filtrar com jq
curl -fsS 'http://localhost:8080/v1/municipios?bioma_id=pampa' \
  | jq '.data[] | {nome, codigo_ibge}'
